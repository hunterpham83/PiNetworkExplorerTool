## 🌐 Overview | Tổng quan

**🇻🇳 Tiếng Việt:**  
Pi Network Explorer Tool là công cụ giúp:
- Tra cứu dữ liệu blockchain Pi Network  
- Kiểm tra ví và giao dịch  
- Giám sát trạng thái Node  
- Khôi phục mnemonic  

**🇺🇸 English:**  
Pi Network Explorer Tool allows you to:
- Explore Pi blockchain data  
- Check wallet & transactions  
- Monitor Node status  
- Recover mnemonic phrases  

---

## ✨ Features | Tính năng

- 🔍 Transaction Explorer  
- 👛 Wallet lookup  
- 🧠 Mnemonic Recovery  
- 🔔 Telegram Alerts  
- ⚡ High Performance  

---

## 🧠 Mnemonic Recovery

**VI:**
- Thiếu 1–2 từ  
- Sai chính tả  
- Sai vị trí từ  

**EN:**
- Missing 1–2 words  
- Typo errors  
- Wrong word order
